# Breeze

**Your space, connected.**

Breeze is a Discord companion that brings the services, interests and utilities you use into one cohesive experience.

## Product direction

- Music: Spotify and Last.fm
- Gaming: Roblox and Fortnite
- Developer: GitHub
- Utilities: crypto information
- AI: helpful AI-powered Discord commands
- Fun: GIFs, quotes and lightweight social commands

## Stack

- React 18
- Vite 5
- Lucide React
- Plain CSS

## Getting started

```bash
npm install
npm run dev
```

## Current status

The first frontend foundation is in place. Integration cards and command listings are currently interface previews; real OAuth connections, APIs, Discord bot commands and secure server-side services still need to be implemented.

Never put provider secrets or bot tokens in frontend code.
